## 📝 关键交互模式

### 1. 创建者流程
```
创建者
  │
  ├─→ 调用 PositionManager.flaunch()
  │
  ├─→ 获得 ERC721 NFT (所有权证明)
  │
  ├─→ 获得预挖代币 (premineAmount)
  │
  └─→ 获得创建者费用分成
```

### 2. 交易者流程
```
交易者
  │
  ├─→ Fair Launch 期间
  │   └─→ 只能买入 (固定价格)
  │
  └─→ Fair Launch 结束后
      ├─→ 可以买入/卖出
      └─→ 正常 Uniswap 交易
```

### 3. 代币持有者流程
```
代币持有者
  │
  ├─→ 可以投票 (ERC20Votes)
  │
  ├─→ 可以控制资金库
  │
  └─→ 可以关闭 BidWall
```
