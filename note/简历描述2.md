项目介绍：Bluelaunch 是一个部署在 Arbitrum上、深度集成 Uniswap V4 Hook 机制的 Memecoin 发射协议。用户一键即可完成代币部署、流动性初始化和公平启动配置。协议核心由三个相互协作的模块组成：MemeLaunch(meme发射)、FairLaunch（公平启动）、InternalSwapPool（内部交换池）。

责任描述：负责设计并实现代币发射主流程（Bluelaunch + PositionManager），包含代币合约部署、ERC721 所有权凭证铸造及 Uniswap V4 流动性池初始化的完整链路

技术实现：

1、MemeLaunch 代币发射主流程：以 tokenId 作为 salt，通过 CREATE2 确定性部署 ERC20 Memecoin 合约，使代币地址在部署前即可预测每次发射同步铸造一枚 ERC721 NFT 作为池的所有权凭证，转让 NFT 即转让池创建者权益（包括手续费分配比例）PositionManager 持有全量初始代币，统一管理 FairLaunch 仓位、宽区间仓位及各模块的手续费流转

2、FairLaunch 公平启动：在 beforeSwap Hook 中判断当前是否处于公平启动窗口，若在窗口内且为 ETH → Token 方向，则通过 BeforeSwapDelta 直接从虚拟仓位填充，完全绕过 Uniswap AMM，使价格在整个窗口内固定在initialTick利用 TickMath.getSqrtPriceAtTick 和 FullMath.mulDiv 在固定 tick 处计算 ETH/Token 的精确兑换比例，支持"精确 ETH 输入"和"精确 Token 输出"两种 swap 模式禁止窗口期内的卖出（revert）和流动性修改，从机制层面杜绝预购抢跑窗口关闭时，根据 nativeIsZero 标志自动计算 tick 范围（单边区间取最窄相邻 tick），分别调用 LiquidityAmounts.getLiquidityForAmount0/1 将 ETH 和剩余 Token 部署为两个永久不可撤回的单边流动性仓位；未售出的 Fair Launch 代币在 PositionManager 侧销毁

3、InternalSwapPool 内部交换池：在 beforeSwap Hook 触发后，若检测到方向为 ETH → Token 且内部有可用 Token 手续费，则调用 SwapMath.computeSwapStep 以当前 pool 价格计算可填充的 ETH/Token 数量，直接通过 PoolManager.take + Currency.settle 完成结算，剩余部分再进入 AMM，从而减少了对链上流动性的冲击
